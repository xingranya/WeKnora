# Chrome 插件（见外知识库助手）

浏览器插件解决的是「看到有用的内容，直接沉淀到公司知识库」这件事。装上之后可以在任意网页的侧边栏直接向见外知识库提问，也可以把当前页面剪藏进去。

当前内部版本为 `v1.3.1`，从「设置 → 集成 → Chrome 插件」下载安装。插件固定连接见外传媒企业知识库，不再提供微信云服务或自定义服务地址选项。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 知识库问答 | 侧边栏对话面板，可切换多个知识库，支持快速 / 深度 / 精确三种回答模式，边浏览边问不打断当前工作 |
| 网页剪藏 | 保存页面 URL、智能提取正文，或手动框选区域；选区支持移动、八向缩放和自动滚动长截图 |
| 文档集采集 | 从当前文档识别侧栏、折叠目录、组件树和分类页，递归发现同站文档并逐篇独立入库；支持进度查看、暂停、继续、取消、重试和断点恢复 |
| 动态文档 | 等待异步内容和跨域 frame 就绪，读取 Shadow DOM、内嵌飞书文档和虚拟滚动区域，保留标题、表格、列表、Callout、链接、附件与可访问图片 |
| 办公站点 | 适配飞书、巨量引擎、抖音规则与生活服务学习中心、腾讯文档、语雀、Notion、WPS、钉钉文档、Google 文档和 Microsoft 365 文档 |
| Markdown 速记 | 内置编辑器随手记想法，一键存进知识库 |
| 快捷键 | 提问、开侧边栏等操作都可自定义快捷键 |

## 怎么配

见外知识库界面里有一个引导页：「设置 → 集成 → Chrome 插件」。步骤：

1. **获取 API Key**：在「设置 → API 信息」复制 API Key。建议单独创建一个 Key，并按需收窄检索与入库能力；
2. **安装插件**：下载 `v1.3.1` ZIP 并解压，打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载解压缩的扩展」并选中包含 `manifest.json` 的目录；
3. **连接知识库**：打开插件，粘贴 API Key，点击「连接知识库」。公司服务地址已经内置。

配置完成后建议先让它列一次知识库或问一个问题，确认凭证与网络都通。

## 排查

| 现象 | 检查点 |
| --- | --- |
| 插件提示连不上 | 当前设备是否能访问公司内网；见外知识库前端和 API 是否正常 |
| 401 / 403 | API Key 是否被吊销；Key 的能力是否覆盖了检索与入库；如果 Key 限定了知识库范围，目标库是否在名单里 |
| 剪藏后知识库里没有 | 到知识库文档列表看解析状态，`processing` 说明在解析中；失败原因见文档详情 |
| 文档集任务暂停 | 当前页面需要登录、验证码验证或访问权限。完成页面操作后，在插件进度区点击「继续」 |
| Edge 提示 `CRX_REQUIRED_PROOF_MISSING` | 删除被停用的扩展，改用 ZIP 解压后通过「加载解压缩的扩展」安装。CRX 仅用于扩展商店或已配置安装来源、允许列表及强制安装策略的企业环境 |

内部页面同时保留 CRX 文件，供扩展商店发布或企业策略分发使用。直接从网页下载并拖入自签名 CRX 会被新版 Edge 的来源校验拦截，普通用户应使用 ZIP 安装包。
