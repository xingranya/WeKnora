见外知识库 API Key 获取说明
插件已固定连接见外传媒企业知识库，无需选择服务或填写地址。你只需从知识库设置中复制自己的 API Key。
1 打开见外知识库
访问 见外知识库，进入公司知识管理平台。
2 登录公司账号
使用你的见外知识库账号完成登录。插件会自动使用公司服务地址。
3 找到「全部设置」
登录后，在页面左下角找到并点击「全部设置」入口，进入用户设置页面。
全部设置
4 打开「API 信息」
在设置页面中，找到并点击「API 信息」选项卡，进入 API 管理页面。
全部设置 › API 信息
5 复制 API Key
在 API 信息页面中，找到 API Key 字段，点击旁边的复制按钮将其复制到剪贴板。
请妥善保管您的 API Key，不要泄露给他人
6 粘贴到插件中
返回插件，将复制的 API Key 粘贴到输入框中，点击「连接知识库」即可完成配置。
如果连接失败，请确认当前设备可以访问公司内网，并检查 API Key 是否完整、有效。
